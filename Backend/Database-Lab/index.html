MINI DESAFÍOS

¿SQL o NoSQL?

Decide qué modelo resulta natural para cada caso. No son reglas universales.

MySQL y PostgreSQL son relacionales; MongoDB es documental. Cassandra usa columnas anchas y Redis suele trabajar con estructuras clave-valor. NoSQL no significa necesariamente JSON ni ausencia de reglas.
