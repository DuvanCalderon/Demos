¿Quién prepara el menú de Capi Bolis?

SSR: el servidor prepara el menú al recibir una solicitud. CSR: envía un programa que prepara el menú en el navegador. SSG: el menú se prepara antes, durante la compilación. Selecciona un componente.

SIMULADOR 01 / NETWORK WATERFALL
Tres estrategias, una página
Configura la red, la CPU y el servidor antes de solicitar. Cada solicitud captura la configuración. Avanza por el tiempo virtual e inspecciona el HTML que recibe el navegador. El catálogo necesita JS para su carrito.

SIMULADOR 02 / HYDRATION
HTML visible ≠ aplicación interactiva
Genera HTML con un carrito inicial. La hidratación conecta comportamiento al HTML existente. Este modelo estricto se detiene si el estado inicial del cliente no coincide con el HTML.
Los frameworks pueden recuperar discrepancias sustituyendo DOM; el comportamiento varía. Enlaces y formularios nativos pueden funcionar sin hidratación.

SIMULADOR 03 / FRESHNESS
¿Qué precio recibe el cliente?
Compara SSR por solicitud, SSR con caché HTML y SSG. El SSG cambia al reconstruir. El SSR cacheado cambia al expirar o invalidar la entrada.
