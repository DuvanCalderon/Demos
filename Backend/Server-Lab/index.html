Un servidor es un rol

Un equipo o programa que ofrece un servicio a otros programas llamados clientes. Tu portátil puede ser servidor si ejecuta un proceso que escucha peticiones.

Piensa en una cafetería: tú haces el pedido (cliente), el mesero lo transporta (red) y la cocina lo prepara (servidor). La despensa sería la base de datos.

Un servidor puede ser físico o virtual. El hardware aporta CPU, memoria, disco y red; el software escucha y responde.

¿Quién hace qué?

Servidor web: entrega recursos HTTP, como HTML o imágenes.

Servidor de aplicaciones: ejecuta reglas de negocio, valida pedidos o calcula precios.

Servidor de bases de datos: almacena y consulta información. No todos los pedidos lo necesitan.

Servidor de archivos o correo: comparte archivos o gestiona mensajes usando sus protocolos.

No confundas servidor con base de datos, ni con la nube: la nube ofrece recursos remotos; un servidor puede estar en tu propia casa.
