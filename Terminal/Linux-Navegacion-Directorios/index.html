🧭 ¿Por dónde empezar?

PRÁCTICA LIBRE

Piensa en el sistema de archivos como un edificio: / es la entrada principal, ~ es tu apartamento y .. es subir a la carpeta que contiene la actual. Escribe pwd para conocer tu ubicación; ls para ver qué hay alrededor; y cd proyectos para entrar en una carpeta.

📚 Tu mapa mental

FEYNMAN

Imagina que cada carpeta es una habitación. Una ruta absoluta da la dirección completa desde la entrada del edificio (/); una ruta relativa te indica cómo llegar desde la habitación donde estás.

pwd¿Dónde estoy?

Imprime la ruta del directorio actual. No te mueve.

ls¿Qué hay aquí?

Enumera contenido. Con -a incluye entradas ocultas.

cd /Ir a la raíz

La barra inicial es el origen de todo el sistema.

cd ..Subir una carpeta

.. señala el directorio padre, no el anterior visitado.

cd .Seguir aquí

. representa el directorio actual.

cd ~Volver a casa

~ apunta al home. cd solo también te lleva allí.

cd -Alternar ubicación

Va al directorio visitado justo antes del actual.

pushd /varGuardar y entrar

Apila tu ubicación actual y se mueve a otra carpeta.

popdRecuperar ubicación

Desapila la ubicación superior y entra en ella.

dirsVer la pila

Muestra la ubicación actual y las direcciones guardadas.

cd ../../Subir dos niveles

Combina segmentos para construir una ruta relativa.

cd /mnt/cWSL y Windows

En WSL, la unidad C: normalmente se monta bajo /mnt/c.

Trampas comunes: / no es ~; cd .. no es cd -; las rutas Linux distinguen mayúsculas y minúsculas; popd necesita una ubicación previamente apilada. Este laboratorio simula una parte de Bash, no ejecuta comandos en tu equipo.
