# Terminal Lab — Simulador interactivo (recreación educativa) ⌨️

Laboratorio autónomo para aprender la diferencia entre **terminal, shell y sistema operativo**, practicar comandos de Linux y evaluar situaciones comunes de la línea de comandos.

**[▶ Abrir Terminal Lab en GitHub Pages](https://duvancalderon.github.io/Demos/Terminal-y-Linea-de-Comandos/07-Terminal-Lab-Interactivo/)** · [← Índice de Terminal](../) · [← Catálogo de Demos](../../)

## Contenido

- **Aprender:** explicación visual de qué son terminal, shell, sistema operativo, rutas y archivos.
- **Laboratorio:** terminal Bash **virtual** con 12 misiones progresivas; incluye `pwd`, `ls -la`, `whoami`, `mkdir`, `cd`, `touch`, `echo`, `cat` y otras acciones. El sistema de archivos es ficticio.
- **Evaluación:** 8 preguntas de opción múltiple, con pistas y explicación de la respuesta.
- **Analizar capturas:** 9 **escenarios visuales recreados** (no las capturas originales de Notion), con lectura de prompts, comandos, salidas, permisos, redirecciones y errores, más pistas y soluciones.
- **Progreso:** aciertos, misiones, XP, guardado local cuando esté permitido, reinicio general y botón para **deshacer el reinicio** dentro de la misma sesión.
- **Sin instalación:** HTML/CSS/JavaScript en un `index.html` independiente.

## Cómo practicar

Entra a **Aprender** para entender las tres capas. Después abre **Laboratorio**, ejecuta comandos virtuales y pulsa **Comprobar misión**. Termina con **Evaluación** y **Analizar capturas**.

**Seguridad:** la terminal no ejecuta Bash real ni puede modificar tu sistema operativo. Es un entorno didáctico JavaScript.

## Sobre la fidelidad al original

La página de Notion incluye el archivo `terminal-lab-interactivo-v4.html`, pero el conector no permitió recuperar el código de ese adjunto.
