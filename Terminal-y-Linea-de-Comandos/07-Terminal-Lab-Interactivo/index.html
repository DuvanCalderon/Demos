La diferencia está en las capas

Una analogía sencilla: la terminal es la ventana, el shell es el traductor y el sistema operativo es quien hace el trabajo.

🪟 Terminal

Es la interfaz donde escribes y lees texto. Ejemplos: Windows Terminal, GNOME Terminal y la terminal integrada de VS Code.

🗣️ Shell

Interpreta lo que escribes y organiza la ejecución de comandos. Ejemplos: Bash, Zsh y PowerShell.

⚙️ Sistema operativo

Administra procesos, archivos, memoria y dispositivos. Linux y Windows ofrecen las funciones que el shell solicita.

📂 Rutas

Con pwd averiguas dónde estás; ls muestra archivos; cd cambia de carpeta.

🧱 Crear archivos

mkdir crea directorios y touch crea archivos vacíos. cat permite leer texto.

🧪 Practicar sin riesgos

Este laboratorio guarda un sistema de archivos ficticio dentro del navegador. No se accede a los archivos reales de tu equipo.
