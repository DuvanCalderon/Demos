🧠 Entiende la idea (Feynman)

Piensa en el sistema de archivos como un archivador. mkdir crea un cajón, touch deja una hoja vacía, cp fotocopia, mv cambia de cajón o etiqueta y rm destruye la hoja. Nada se mueve hasta que indiques dónde.

touchmkdir -pecho >cp -rmvrm -r

Las rutas relativas salen de tu ubicación actual (pwd). Una ruta absoluta empieza en /.

⚠️ Errores típicos del mundo real

rm carpeta/ no borra directorios: requiere rm -r. Para directorios vacíos, prueba rmdir.

cp carpeta copia falla sin -r. mkdir -p a/b sí crea padres faltantes.

⚡ rm -rf en una terminal real puede eliminar datos sin papelera ni confirmación. Aquí se solicita confirmación educativa.

Para nombres con espacios utiliza comillas: touch "mi archivo.txt". Para aprender opciones consulta man comando.
