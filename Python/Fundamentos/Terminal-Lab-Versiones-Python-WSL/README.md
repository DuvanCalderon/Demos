# Terminal Lab — Versiones de Python, WSL y salida del intérprete (4 retos) 💻

Micro laboratorio interactivo para aprender a consultar la versión de Python en distintos entornos y a reconocer cuándo estás dentro del intérprete interactivo de Python.

**[▶ Abrir Terminal Lab en GitHub Pages](https://duvancalderon.github.io/Demos/Python/Fundamentos/Terminal-Lab-Versiones-Python-WSL/)** · [← Catálogo principal](https://duvancalderon.github.io/Demos/)

## Qué practicarás

1. **Windows / PowerShell:** consultar la versión instalada mediante `python --version` (o `py --version`).
2. **Ubuntu / WSL:** usar `python3 --version` desde la terminal de Linux.
3. **PowerShell → WSL:** consultar la versión de Ubuntu sin salir de Windows mediante `wsl python3 --version`.
4. **Intérprete interactivo:** identificar el indicador `>>>` y volver a la terminal mediante `exit()` o `quit()`. Incluye una captura de pantalla incrustada que puedes ampliar.

- Cuatro retos con entrada escrita, comprobación automática, explicaciones y pistas progresivas.

- Navegación entre ejercicios, sonidos opcionales, puntuación y progreso.
