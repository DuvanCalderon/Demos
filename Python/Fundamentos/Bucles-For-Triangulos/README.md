# Python Loop Lab — Triángulos numéricos y bucles `for` 🐍

Laboratorio web interactivo para aprender `for` anidados, `range()` y patrones de números impares a través de **15 retos**, un simulador paso a paso y un editor didáctico.

**[▶ Abrir el laboratorio en GitHub Pages](https://duvancalderon.github.io/Demos/Python/Fundamentos/Bucles-For-Triangulos/)** · [← Catálogo principal](https://duvancalderon.github.io/Demos/)

## Qué incluye

- **Simulador:** controla cada iteración, cambia la velocidad, avanza o retrocede y compara “límite impar” con “altura exacta”.
- **15 retos:** cinco básicos, cinco intermedios y cinco avanzados, con pistas, soluciones, puntuación y reintentos.
- **Código:** editor de un subconjunto de Python implementado en JavaScript, con salida inmediata y cinco pruebas automáticas por modalidad.
- **Conceptos:** explicaciones sobre `range()`, bucles anidados, `print(end=" ")`, sangrías y errores frecuentes.
- **Progreso:** guardado en el almacenamiento local del navegador; no requiere cuentas ni servidor.

## Ejecución

Abre `index.html` en un navegador moderno o usa el enlace de GitHub Pages. El laboratorio no necesita dependencias externas.

**Nota:** El editor implementa un intérprete educativo limitado en JavaScript: **no ejecuta Python completo** ni soporta módulos, `input()` o funciones arbitrarias. Para ejecutar Python real, usa tu entorno Python o un cuaderno Jupyter.
