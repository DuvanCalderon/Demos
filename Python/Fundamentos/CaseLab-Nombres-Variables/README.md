# CaseLab — camelCase, PascalCase y snake_case (45 retos) 💻

Laboratorio interactivo para practicar convenciones de nomenclatura en programación y aprender a escribir identificadores correctos.

**[▶ Abrir CaseLab en GitHub Pages](https://duvancalderon.github.io/Demos/Python/Fundamentos/CaseLab-Nombres-Variables/)** · [← Catálogo principal](https://duvancalderon.github.io/Demos/)

## Contenido

- **45 retos de escritura:** 5 ejercicios por nivel (básico, intermedio, avanzado) para cada una de las tres convenciones (camelCase, PascalCase y snake_case).
- **Validación automática:** comprueba mayúsculas, separadores y orden de las palabras; acepta respuestas con o sin tildes según las reglas descritas en el demo.
- **Pistas y soluciones:** ayudas progresivas, explicación y repetición de ejercicios.
- **Laboratorio de conversiones:** transforma tus propias frases en los tres estilos de nombres y copia los resultados.
- **Seguimiento:** contador de ejercicios resueltos, porcentaje, racha de aciertos y reinicio total del progreso.

## Cómo usarlo

Abre `index.html` directamente en un navegador o utiliza GitHub Pages. No requiere instalaciones ni dependencias externas. Elige un nivel y una convención, escribe el nombre solicitado y comprueba tu respuesta. Usa el laboratorio para explorar otras frases.

El progreso se almacena en el navegador cuando `localStorage` está disponible, o temporalmente durante la sesión cuando se dispone únicamente de `sessionStorage`. El progreso no se sincroniza entre Notion y GitHub Pages.
