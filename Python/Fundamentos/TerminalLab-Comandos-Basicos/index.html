01 · INTERFAZ

PowerShell no es Python

PowerShell es como la recepción de un edificio: recibe comandos del sistema. Python es una herramienta a la que puedes entrar desde esa recepción.

PS C:\Users\Estudiante> python
>>> 2 + 3
5
>>> exit()
PS C:\Users\Estudiante>
02 · INTERPRETACIÓN

REPL = experimentar

Lee, evalúa, muestra el resultado y repite. Se usa para probar ideas rápidamente. En cambio, un archivo .py almacena instrucciones para reutilizarlas.

>>> precio = 15000
>>> 3 * precio
45000
03 · ARCHIVOS

La carpeta importa

Si escribes python saludo.py, Python intenta abrir ese archivo desde tu ubicación actual, salvo que especifiques otra ruta.

dir
cd Documentos
python saludo.py
04 · PATH

PATH es un directorio de búsqueda

Windows consulta ciertas carpetas para localizar ejecutables. Quitar Python de PATH no lo desinstala. El lanzador py puede funcionar por separado.

python --version
py --version
$env:Path -split ';'
05 · ERRORES

¿Qué parte falló?

“No se reconoce python” implica un problema al encontrar el ejecutable. “No se puede abrir el archivo” significa que Python sí arrancó, pero no halló el archivo indicado.

python fantasma.py
# Error: archivo inexistente
06 · PENSAMIENTO LÓGICO

Escribir y ejecutar son pasos diferentes

Escribe un programa, guárdalo y ejecútalo. Modificar el editor sin guardar no cambia el programa que está almacenado. ¡Este error pasa incluso en equipos profesionales!

precio = 15000
cantidad = 3
print(precio * cantidad)
