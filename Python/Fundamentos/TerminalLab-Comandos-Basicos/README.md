# TerminalLab — Comandos básicos de Python (15 retos) 🐍

Laboratorio de terminal y Python para aprender haciendo con **15 desafíos** graduados, un PowerShell simulado, el modo interactivo de Python y un editor virtual de archivos `.py`.

**[▶ Abrir TerminalLab en GitHub Pages](https://duvancalderon.github.io/Demos/Python/Fundamentos/TerminalLab-Comandos-Basicos/)** · [← Catálogo de Demos](https://duvancalderon.github.io/Demos/)

## ¿Qué incluye?

- **Terminal PowerShell:** ejecutar `help`, `dir`, `pwd`, `cd`, `mkdir`, `python`, `py` y otros comandos compatibles con el simulador.
- **Python interactivo (REPL):** experimentar con expresiones, variables, `print()`, operaciones numéricas y estructuras sencillas.
- **Editor de archivos `.py`:** crear, abrir, editar, guardar y ejecutar programas simulados.
- **Configuración del entorno:** activar y desactivar el acceso a Python desde PATH y el lanzador `py`.
- **15 retos:** pistas, solución explicada, validación de acciones, puntos, navegación y seguimiento del progreso.
- **Confirmaciones propias:** reiniciar el laboratorio o descartar cambios pendientes sin depender de cuadros de confirmación bloqueados en Notion.

## Cómo usarlo

Abre `index.html` o entra directamente mediante GitHub Pages. Escribe un comando en la terminal y pulsa **Ejecutar** o **Enter**. Selecciona los retos desde el panel lateral y prueba las acciones indicadas. Guarda tus archivos del editor antes de ejecutarlos para comprobar su comportamiento.

**Importante:** es una simulación educativa JavaScript y **no ejecuta Python real ni comandos del sistema operativo**. Los archivos creados son virtuales y permanecen dentro de la simulación.

El progreso se guarda en el navegador cuando el almacenamiento local está permitido; Notion y GitHub Pages no comparten el mismo almacenamiento automáticamente.
