¿Qué es un método de string?

Piensa en una fotocopiadora inteligente: recibe una hoja con texto y te devuelve otra versión con cambios. La hoja original no se altera. Así funcionan .upper(), .lower() y .strip().

nombre = "  aDa  "
limpio = nombre.strip().capitalize()
print(limpio)  # Ada
print(nombre)  # "  aDa  " (sin cambios)

⚠️ Trampas que debes dominar
String ≠ número"5" + "5" produce "55", mientras que 5 + 5 produce 10.
len() es una función, no un método de stringCorrecto: len(texto). Incorrecto: texto.len().
.strip() no elimina espacios interiores" a  b ".strip() conserva los dos espacios que separan las letras.
in busca fragmentos y distingue mayúsculas"pan" in "pantalla" es True, pero "python" in "Python" es False.
Los métodos no modifican el texto originaltexto.upper() no reasigna texto. Usa texto = texto.upper() si necesitas guardar el cambio.
Unicode y emojislen("🐍") es 1, pero algunas secuencias visibles pueden tener más de un punto de código.
