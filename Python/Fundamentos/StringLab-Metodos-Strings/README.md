# StringLab — Métodos esenciales para strings en Python 🐍

Laboratorio interactivo, independiente y sin dependencias externas para dominar **14 operaciones de cadenas**, resolver **18 retos** y superar **4 misiones** encadenando métodos.

**[▶ Abrir StringLab en GitHub Pages](https://duvancalderon.github.io/Demos/Python/Fundamentos/StringLab-Metodos-Strings/)** · [← Catálogo principal](https://duvancalderon.github.io/Demos/)

## Contenido

- **Laboratorio:** escribe y transforma cadenas; compara resultados, tipos e índices de caracteres.
- **14 operaciones:** `strip()`, `lstrip()`, `rstrip()`, `upper()`, `lower()`, `capitalize()`, `replace()`, `len()`, `in`, `not in`, `count()`, `find()`, `startswith()` y `endswith()`.
- **Constructor:** resuelve 4 misiones combinando operaciones sin salir de la página.
- **Retos:** 18 ejercicios básicos, intermedios y avanzados, con corrección inmediata, pistas y soluciones explicadas.
- **Progreso:** puntos y actividades completadas guardados en el navegador cuando está disponible `localStorage`.

## Cómo usarlo

Abre `index.html` en tu navegador o entra por GitHub Pages. No hay servidor, instalación, conexión a APIs ni paquetes externos.

> **Alcance:** el laboratorio reproduce operaciones de Python mediante JavaScript para enseñar los conceptos; no ejecuta instrucciones Python arbitrarias. Para ejecutar código Python general necesitas un intérprete de Python.
