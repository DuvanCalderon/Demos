# Python Type Dojo — Tipos, booleanos y colecciones (103 retos) 🧪

Laboratorio interactivo para aprender haciendo y entrenar los fundamentos de Python mediante 103 ejercicios de distintos niveles y un simulador de colecciones.

**[▶ Abrir Python Type Dojo en GitHub Pages](https://duvancalderon.github.io/Demos/Python/Fundamentos/Type-Dojo-Tipos-Datos/)** · [← Catálogo de Demos](https://duvancalderon.github.io/Demos/)

## Qué incluye

- **103 retos** distribuidos entre tipos de datos (20), booleanos (21), colecciones (22), predicción de salidas (21) y detección de errores (19).
- **Tres niveles**: básico, intermedio y avanzado.
- **Entrenamiento**: ejercicios de selección y respuesta escrita, pistas graduales, soluciones explicadas y tandas de práctica.
- **Simulador**: experimenta con listas, tuplas, diccionarios y conjuntos, observando cambios y resultados de las operaciones.
- **Seguimiento de progreso**: XP, rachas, estadísticas, registro de errores y reinicio. Guarda el estado localmente cuando el navegador permite `localStorage`.

## Uso

Abre `index.html` directamente en un navegador o utiliza GitHub Pages. No requiere instalaciones, módulos ni servidor propio. Elige un nivel y una categoría de entrenamiento, intenta resolver los retos y utiliza el simulador para comprobar cómo se comportan las colecciones.

> El simulador implementa reglas educativas en JavaScript; no ejecuta Python arbitrario. El progreso de GitHub Pages y el del demo incrustado en Notion no se sincronizan automáticamente entre dominios.
