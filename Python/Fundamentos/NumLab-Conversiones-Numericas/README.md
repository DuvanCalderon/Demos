# Python NumLab — Conversión de tipos numéricos (18 retos) 🐍

Laboratorio educativo e interactivo para entender las conversiones numéricas de Python, la truncación, los límites de `random.randrange()` y la precisión de los números `float`.

**[▶ Abrir NumLab en GitHub Pages](https://duvancalderon.github.io/Demos/Python/Fundamentos/NumLab-Conversiones-Numericas/)** · [← Catálogo principal](https://duvancalderon.github.io/Demos/)

## Qué incluye

- **Conversor:** experimentar con `int()`, `float()` y `complex()`, y observar resultados y errores.
- **Truncamiento:** comparar `int()`, `math.floor()` y distintas situaciones con negativos.
- **Azar:** explorar intervalos de `random.randrange()` con una simulación de tiradas.
- **Precisión:** observar los límites de representación binaria y cuándo conviene usar `decimal.Decimal`.
- **18 retos:** 6 básicos, 6 intermedios y 6 avanzados con pistas, retroalimentación y soluciones explicadas.
- **Progreso:** XP, guardado local cuando es posible, reinicio y opción de respaldar/restaurar mediante un código.

## Cómo utilizarlo

Abre el enlace de GitHub Pages o el archivo `index.html` directamente en un navegador. No requiere instalación ni dependencias. Navega entre los simuladores, experimenta y completa los retos. Para conservar el avance entre dispositivos o contextos con almacenamiento bloqueado utiliza la opción **Respaldar / restaurar avance**.

## Notas técnicas

- Es una simulación educativa implementada en JavaScript: **no ejecuta Python real** y no sustituye su intérprete.
- GitHub Pages y Notion usan orígenes diferentes y **no comparten automáticamente el progreso** almacenado en el navegador. Usa la copia de seguridad para trasladar el avance.
- Esta versión está adaptada a navegación web independiente y conserva la implementación corregida con respaldos.
