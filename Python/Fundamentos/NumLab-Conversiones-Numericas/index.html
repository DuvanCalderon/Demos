Una idea antes de escribir código

Imagina que una tienda registra el precio de un producto de varias formas. Python necesita saber si está trabajando con un número, un decimal o un texto. Convertir es pedirle que represente el mismo dato de otra manera, cuando la conversión tiene sentido.

🔢

Enteros · int

Para contar productos, personas o unidades. int(8.9) es 8: elimina los decimales, no redondea.

📐

Decimales · float

Para temperaturas, medidas y cálculos aproximados. No todos los decimales caben exactamente en memoria.

🧲

Complejos · complex

Un número con parte real e imaginaria. Aparece en señales, electrónica y matemáticas.

¿Qué regla conviene recordar?

int() trunca

Convierte números reales finitos a enteros, acercándose a cero. int(-4.8) produce -4.

float() aproxima

Representa decimales en coma flotante. float("3.5") sirve, pero float("tres") no.

complex() amplía

Puede agregar una parte imaginaria a un real. La conversión directa de complex a int falla.

04 / Detrás de los decimales

Cuando 0.1 + 0.2 no es exactamente 0.3

Una calculadora humana puede escribir decimales exactos. Los números float del computador suelen usar aproximaciones binarias. Experimenta para ver la diferencia.

Elige un experimento
print(0.1 + 0.2)

Los cálculos del demo usan números JavaScript de doble precisión, equivalentes en formato binario IEEE 754 a los float habituales de Python para estos ejemplos.

Resultado observado
Sin formatear
0.30000000000000004
Mostrado con 2 decimales
0.30
Formatear cambia cómo se muestra el número, no corrige su aproximación interna.
Los números como 0.1 no tienen representación binaria finita. El computador guarda el valor representable más cercano; pequeños errores pueden acumularse. Para dinero exacto considera decimal.Decimal o enteros en unidades mínimas.
Caso real · Tienda en línea

¿Qué harías si construyes una caja registradora?

Evita depender de float para cálculos monetarios que exijan exactitud decimal. En Python puedes utilizar Decimal("0.1") + Decimal("0.2"), que da exactamente Decimal('0.3') para ese ejemplo. El redondeo y las reglas contables siguen siendo decisiones de negocio.
