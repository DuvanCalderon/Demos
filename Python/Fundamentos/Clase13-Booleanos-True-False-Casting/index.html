📖 Reglas claras y trampas frecuentes

Despliega cada regla cuando necesites un recordatorio.

1. True y False van con mayúscula inicial

En Python son literales booleanos: True y False. true y false no están definidos por defecto y producirán NameError.

2. bool("False") vale True

El texto "False" no es el valor booleano False. Como es un string no vacío, bool("False") devuelve True. Igual sucede con "0" y " ".

3. Estos valores son falsy

False, None, 0, 0.0, "", [], () y {}, entre otros contenedores vacíos. Los números negativos son truthy.

4. isinstance(True, int) es True

En Python, bool es una subclase de int. Por eso isinstance(True, int) es True, pero type(True) == int es False. type(True) es exactamente bool.

5. = no es lo mismo que ==

x = 5 asigna un valor. x == 5 produce un booleano al comparar. Además, "5" == 5 es False: los tipos importan.

6. and / or / not

Con booleanos: and exige las dos condiciones verdaderas, or exige al menos una, y not invierte el resultado. Con otros operandos, and y or pueden devolver un valor no booleano.

7. bool() y casting no ejecutan expresiones de texto

El laboratorio admite literales de práctica y no implementa todo Python. Es intencional: nunca se ejecuta código enviado por el usuario. Para Python completo, usa tu propio intérprete.
