# PATH LAB — Variables de entorno de Python en Windows 🧪

Laboratorio interactivo de Windows y Python para experimentar con **PATH**, PowerShell, localización de ejecutables y errores habituales de configuración, sin modificar el equipo real.

**[▶ Abrir PATH LAB en GitHub Pages](https://duvancalderon.github.io/Demos/Python/Fundamentos/PATH-Lab-Variables-Entorno/)** · [← Catálogo de Demos](https://duvancalderon.github.io/Demos/)

## Contenido

- **Laboratorio de PATH:** añade, elimina, edita y reordena rutas de usuario y de sistema; observa la prioridad de búsqueda y diferencias entre sesiones.
- **Terminal PowerShell simulada:** utiliza `python --version`, `where.exe python`, `py`, `pip` y otros comandos admitidos para diagnosticar situaciones educativas.
- **Escenarios:** Python configurado, PATH incompleto, alias de Windows, cuentas de usuario y sesiones con cambios pendientes.
- **Ocho misiones:** objetivos comprobados a partir de tus acciones reales dentro de la simulación, con pistas progresivas y explicaciones.
- **Examen interactivo:** diez preguntas con corrección, explicaciones, mejor calificación y repetición.
- **Progreso:** XP, misiones superadas y resultados del examen guardados localmente cuando el navegador permite `localStorage`.

## Cómo usarlo

Abre `index.html` directamente en el navegador o entra por GitHub Pages. Navega a **Laboratorio**, modifica las rutas y prueba comandos en la terminal. Después ve a **Misiones** o **Examen**. El botón **Volver al catálogo** lleva a la página principal de Demos.

La simulación está construida con HTML, CSS y JavaScript, sin dependencias de instalación. Una captura ilustrativa y los enlaces de documentación externa pueden requerir conexión a Internet.

> **Importante:** no ejecuta PowerShell ni Python reales y no cambia las variables de entorno del equipo. Algunas reglas de resolución de comandos de Windows están simplificadas con fines educativos. El progreso del demo en Notion y el de GitHub Pages no se sincronizan automáticamente.
