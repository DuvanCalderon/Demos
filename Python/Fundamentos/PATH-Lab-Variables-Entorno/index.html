01 · El concepto

Un directorio, no un motor

Imagina que PATH es la lista de direcciones de una recepcionista: sabe dónde buscar el programa, pero no lo instala ni lo fabrica.

⌨️
PASO 01

🗂️
PASO 02

Revisa las ubicaciones disponibles en el entorno de la terminal y encuentra el primer ejecutable compatible.

🐍
PASO 03

Ejecuta Python

Si encuentra python.exe, lo inicia. Si no lo encuentra, falla o puede intervenir un alias de Windows.

La regla de oro

Instalar ≠ agregar al PATH

Tener Python instalado es como tener una tienda abierta. Agregar su carpeta al PATH es poner la dirección de esa tienda en el directorio del sistema.

✓Instalado y en PATH: puedes escribir python desde casi cualquier carpeta.
✓Instalado, sin PATH: aún puedes invocarlo mediante su ruta absoluta, un lanzador disponible o desde un IDE configurado.
✓PATH cambiado: una terminal ya abierta puede seguir usando el entorno anterior; hay que iniciar otra desde un proceso actualizado.

Comandos útiles de PowerShell

Errores típicos y su explicación

!
«python no se reconoce»: revisa instalación, PATH, alias y desde qué proceso abriste la terminal.
!
«py funciona pero python no»: el lanzador/administrador puede localizar una instalación aunque el comando python no esté resolviéndose igual.
!
«pip no se reconoce»: prueba python -m pip para usar pip del intérprete seleccionado; el comando directo suele necesitar una carpeta Scripts accesible.
!
«En VS Code sigue fallando»: una terminal creada por una aplicación ya abierta puede heredar un PATH anterior; reinicia esa aplicación.
!
«En WSL sí funciona»: Ubuntu y Windows son entornos distintos, con comandos y rutas diferentes.
