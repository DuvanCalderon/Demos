De la matemática al código
Una raíz es una entrada que produce cero. Un número crítico de una función diferenciable se obtiene buscando ceros de su derivada. Un punto fijo es una entrada que sale igual: g(x)=x.
import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import bisect, fixed_point, newton

x = np.linspace(-1, 6, 1000)
plt.plot(x, h(x))  # define h antes
plt.axis([-1, 6, -1, 1])
plt.grid()
plt.show()
Trampas: ** en Python eleva a una potencia; ^ es XOR. np.arctan es arctangente, no 1/tan. np.linspace incluye ambos extremos por defecto. El zoom no aumenta el número de muestras. Bisección exige continuidad y cambio de signo (o raíz en un extremo). Newton necesita una derivada no nula en el paso; la convergencia cuadrática es local para raíces simples bajo condiciones apropiadas. Una raíz de multiplicidad impar también puede cruzar el eje.

Al reescribir 100−100cos(2x)=200sin²(x) y muestrear con mayor resolución aparecen siete raíces simples, incluidas parejas cerca de 0 y π. En π la derivada no es cero.
