# Excel Interface Lab — Simulador de la interfaz 📊

Laboratorio web educativo para aprender a reconocer y utilizar las zonas principales de la interfaz de Excel de escritorio mediante exploración, una hoja editable y 12 retos progresivos.

**[▶ Abrir el simulador en GitHub Pages](https://duvancalderon.github.io/Demos/Excel/Simulador-Interfaz-Basica/)** · [← Catálogo principal](https://duvancalderon.github.io/Demos/)

## Funcionalidades

- **Exploración de 8 zonas:** barra de acceso rápido, título, cinta de opciones, cuadro de nombres, barra de fórmulas, filas y columnas, pestañas de hojas, barra de estado.
- **Hoja simulada con 10 columnas × 14 filas:** selecciona celdas, introduce números o textos y fórmulas sencillas como `=SUMA(B2:B4)`.
- **Cinta interactiva:** cambia entre Inicio, Insertar, Fórmulas, Datos y Vista; aplica negrita, relleno azul o centrado.
- **Hojas:** Ventas, Inventario y Resumen; cambia de pestaña, renombra hojas y añade nuevas.
- **Acceso rápido:** Guardar (simulado), Deshacer y Rehacer.
- **12 retos:** navegación, escritura, fórmulas, pestañas, formato y gestión de hojas, con pistas y comprobación.
- **Progreso local** con guardado mediante `localStorage` cuando esté permitido y confirmaciones para reiniciar o restaurar.

## Cómo usarlo

Abre el demo en GitHub Pages o `index.html` directamente en tu navegador. Comienza por **Explorar** para conocer cada zona. En **Laboratorio**, edita celdas desde la barra de fórmulas (pulsa Enter para confirmar). En **Retos**, cumple los objetivos y pulsa **Comprobar reto**.

## Importante: versión recreada

**Este simulador es una recreación educativa y NO una copia del HTML original de Notion.** Aunque se encontró el bloque adjunto en Notion, el conector no permitió obtener sus bytes de contenido. El HTML original se mantiene incrustado en Notion y no ha sido alterado.

El nuevo simulador tampoco ejecuta Microsoft Excel ni abre, exporta o verifica archivos `.xlsx` reales; las herramientas y las fórmulas son versiones didácticas y simplificadas.
