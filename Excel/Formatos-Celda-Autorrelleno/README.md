# Excel Lab — Formatos de celda y autorrelleno 📊

Laboratorio educativo web para practicar el concepto de **formatos de celda** y **autorrelleno** mediante una hoja simulada e interacciones directas.

**[▶ Abrir Excel Lab en GitHub Pages](https://duvancalderon.github.io/Demos/Excel/Formatos-Celda-Autorrelleno/)** · [← Catálogo general](https://duvancalderon.github.io/Demos/)

## Características

- **12 retos** sobre formato de moneda, porcentajes, fechas, negrita, alineación, relleno, decimales y series.
- **Hoja simulada A1:F12** con celdas seleccionables y operaciones sobre rangos.
- **Autorrelleno interactivo** de series numéricas, días, meses e identificadores.
- Pistas, comprobación automática de cada objetivo, explicación y seguimiento del progreso.
- Diseño responsive, un solo `index.html` con CSS y JavaScript; no requiere librerías ni instalación.

## Cómo usarlo

Abre el enlace de GitHub Pages, selecciona uno de los 12 retos, escribe el rango de celdas, escoge la operación y pulsa **Aplicar a la hoja**. Después pulsa **Comprobar reto**. Usa **Pista** y **Ver solución** si lo necesitas.

Los datos del simulador se guardan en el navegador cuando `localStorage` está habilitado. Puedes reiniciar los cambios o todo el progreso.

## Transparencia sobre la versión

**Esta es una recreación educativa, no una migración exacta del HTML original de Notion.** El adjunto de Notion estaba disponible, pero la integración no devolvió sus bytes de contenido para publicarlos. Por eso construimos una nueva versión web funcional con el mismo tema. El archivo incrustado de Notion sigue siendo el original y **no se ha modificado**.

Este demo simula una hoja: **no modifica ni evalúa archivos .xlsx reales**. Para practicar directamente con Excel de escritorio se debe utilizar Microsoft Excel.
